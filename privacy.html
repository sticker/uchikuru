プライバシーポリシー

基本方針

本アプリは、機能の提供のために以下に列挙するデータを収集・処理します。開発者は独自のサーバーを運用しておらず、収集したデータが開発者のサーバーに送信・蓄積されることはありません。データはすべて (1) お使いのヘッドセット内に保存されるか、(2) 機能の提供に必要な範囲で下記の各サービスとの間で直接やり取りされます。

収集・処理するデータの一覧

  • Meta ユーザー ID・基本プロフィール（ユーザー名・プロフィール写真） — アプリ内購入の照会・復元のため、Meta Platform SDK を通じてアクセスします。端末内での購入判定にのみ使用し、表示・保存・外部送信・第三者提供はしません。
  • 購入情報（エンタイトルメント） — どの追加コンテンツを所有しているかを Meta Horizon Store から取得し、該当コンテンツの解錠に使用します。決済情報（カード番号等）には一切アクセスしません。
  • VRoid Hub のアカウント連携情報（任意） — ログインした場合、アクセストークンとダウンロードしたモデルをヘッドセット内に保存し、モデルの取得・表示に使用します。
  • 会話テキスト — キャラクターの返答生成のため、あなたが選択した会話の内容が Google Gemini API に送信されます。開発者がその内容を受け取ったり保存したりすることはありません。
  • アプリが端末内に保存するデータ — 設定、部屋のレイアウトとキャラクターの配置・大きさ、キャラクターとの思い出（一緒に遊んだゲーム名などの記録）、撮影した写真、ユーザーが追加したモデル・音声ファイル・API キー。すべてヘッドセット内にのみ保存され、外部に送信されません。
  • 空間データ（部屋のスキャン） — Meta Horizon OS が管理し、キャラクターの配置・遮蔽のために端末内でのみ参照します。室内の映像・形状を保存・送信することはありません。

VRoid Hub 連携（任意）

  • キャラクターモデルの取得のため、pixiv 社の VRoid Hub にログインできます。ログインは VRoid Hub の公式 OAuth 画面で行われ、本アプリはアクセストークンとモデルデータのみを受け取ります。パスワードが本アプリに渡ることはありません。
  • トークンとダウンロードしたモデルは、ヘッドセット内にのみ保存されます。
  • VRoid Hub の利用は pixiv 社のプライバシーポリシーに従います。

会話機能

  • キャラクターとの会話の生成に Google Gemini API を利用します。会話のテキストが Google に送信されます。音声・映像・室内のスキャンデータが送信されることはありません。
  • Google の API 利用は Google のプライバシーポリシーに従います。

YouTube 視聴

動画の再生は YouTube の埋め込みプレイヤーで行われ、Google の利用規約・プライバシーポリシーが適用されます。

リモートデスクトップ（有料追加コンテンツ）

お使いの Mac の画面を表示する機能は、同一ネットワーク内の Mac とヘッドセットが直接通信します。画面の映像が外部サーバーを経由することはありません。

空間データ

部屋のスキャンデータ（Scene / Passthrough）は Meta Horizon OS が管理し、キャラクターの配置・遮蔽のためにデバイス内でのみ利用されます。本アプリが室内の映像・形状を外部に送信することはありません。

購入情報

追加コンテンツの購入は Meta Horizon Store の決済基盤で処理されます。本アプリは購入の有無（エンタイトルメント）のみを参照し、決済情報には一切アクセスしません。

購入したコンテンツの所有者を判定するため、Meta Horizon Store のアプリ内購入機能を利用します。この確認のために、本アプリは Meta Platform SDK を通じてお客様のユーザー ID と基本プロフィール（ユーザー名・プロフィール写真）にアクセスすることがあります。これらは購入の照会・復元のためだけに端末内で使用され、本アプリが表示・保存・外部送信・第三者提供することはありません。フレンドリストその他のソーシャル情報にはアクセスしません。

分析・広告

本アプリは、アクセス解析・行動トラッキング・広告 SDK を含みません。

データの削除

本アプリが扱うデータは、次のいずれの方法でも削除できます。

  • アプリ内から: 設定メニュー → ルーム → 「アプリのデータをすべて消す」。写真・設定・ログイン情報・思い出を含む、本アプリが端末内に保存したすべてのデータを消去します。
  • アンインストール: アプリを削除すると、端末内のデータはすべて削除されます。
  • 削除のリクエスト: 下記のお問い合わせ先にご連絡いただければ対応します（開発者はサーバーにデータを保持していないため、通常は上記の端末内削除ですべて完了します）。

連携先サービスに保存されたデータの削除は、各サービスの手続きに従います: Meta アカウントのデータは Meta、VRoid Hub のデータは pixiv、Gemini API に送信されたデータは Google。

Privacy Policy (English)

"Uchi, Kuru?" (the App) collects and processes the data listed below to provide its features. The developer operates no servers of its own, and no collected data is ever sent to or stored by the developer. All data either stays on your headset or flows directly between your device and the services named below.

Data the App collects and how it is used:

  • Meta user ID and basic profile (username, profile picture) — accessed through the Meta Platform SDK to verify and restore in-app purchases. Used on-device only; never displayed, stored, transmitted or shared.
  • Purchase entitlements — read from the Meta Horizon Store to unlock the add-ons your account owns. The App never accesses payment details.
  • VRoid Hub account link (optional) — if you sign in, the access token and downloaded models are stored on the headset and used to fetch and display your models.
  • Conversation text — the dialogue you choose is sent to the Google Gemini API to generate character replies. The developer never receives or stores it.
  • Data stored on the device — settings, room layout and character placement, shared memories (e.g. which games you played together), photos you take, and any models, voice files or API keys you add yourself. Stored on the headset only.
  • Room scan data — managed by Meta Horizon OS and read on-device only, for character placement and occlusion. Never stored or transmitted by the App.

Data deletion: you can delete everything the App has stored in any of three ways: in-app via Settings → Room → "Erase all app data" (removes photos, settings, logins and memories); by uninstalling the App; or by contacting us at the address below (since the developer holds no data on any server, on-device deletion normally completes the process). For data held by connected services, please use the respective providers' procedures: Meta account data via Meta, VRoid Hub data via pixiv, Gemini API data via Google.

The App contains no analytics or advertising SDKs.
